# Reçu et finalité

index.ts journalise le hash renvoyé par l’envoi et produit un lien Scrollscan. Un hash accepté par le fournisseur ne prouve pas encore l’inclusion ni la finalité. Le suivi doit relire le reçu, son statut et les événements du contrat. Cette distinction complète le simple affichage de l’URL d’explorateur dans le script.
